# AWS Study Notes

AWS Skill Builderの動画トランスクリプトを、図・比較表・復習問題で理解できる静的HTML教材へ再構成する、個人学習用のプロジェクトです。動画の置き換えではなく、サービスの役割と関係を短時間で把握・復習するために使います。

**初期のModule 2モデルを採用し、Module 1〜7を公開しています。** 元データは親ディレクトリの`../scripts/`にある7ファイルです。`module.txt`はModule 1、`module2.txt`〜`module7.txt`は対応する番号です。元データは変更していません。将来の対象は13モジュールですが、Module 8以降のページ・タイトルはまだ作成していません。

## ディレクトリ

```text
aws-skillbuilder-notes/
├── index.html                       # 7モジュールへの入口
├── modules/module-01.html〜07.html   # 本文・図・表・復習・公式資料
├── assets/
│   ├── css/style.css                # 初期モデルの共通デザイン・色・表示ルール
│   ├── css/curriculum.css           # 包含・フロー・データモデルなどの追加部品
│   ├── js/main.js                   # 目次の現在位置・印刷時の回答表示
│   └── images/                      # 将来の画像置き場
├── docs/
│   ├── design-guidelines.md         # 文章・デザイン・図解・追加手順
│   ├── curriculum-review.md         # 入力との対応・補足・表示確認の記録
│   └── qa-curriculum/               # 表示確認の画像・測定結果
├── prototypes/                      # 不採用案を含む試作の履歴
└── README.md
```

`prototypes.css`と`focus.css`は試作専用です。通常の教材には読み込みません。過去の比較ページとレビュー文書は履歴として残しています。

## ローカルで見る

`index.html`をブラウザーで直接開きます。ビルド、インストール、オンライン接続は不要です。公式資料のリンクを読む際だけインターネット接続が必要です。

任意で、このディレクトリからローカルサーバーを使えます。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザーで`http://127.0.0.1:8765/`を開きます。終了はターミナルでCtrl+Cです。

## 新しいModuleを追加

1. `docs/design-guidelines.md`と対象のトランスクリプトを読み、番号と内容を確認する。指示と現状が異なる場合は先に確認する。
2. 学習目標・概念のまとまり・サービス間の関係を整理する。仕様や単純化の補足は最新のAWS公式資料で確認する。
3. `modules/module-NN.html`を作成し、共通CSS 2ファイルとJSを相対パスで読み込む。章数と図の方式は内容に応じて選ぶ。
4. ホームにカードを追加し、実在する隣接ページのPrevious / Nextを更新する。公開数・READMEも更新する。
5. 320 / 390 / 600 / 820 / 1093 / 1280px幅で、本文・図表・見出し・改行・回答を開いた状態・リンクを確認して修正する。新しい共通部品と検証結果を記録する。

認証、DB、バックエンド、CMS、React、デプロイは含みません。教材の文章や図の更新に、生成ツールや外部ライブラリは不要です。
